# One Point Strike

## Installera för Windows

**[Ladda ned OPS-installern](https://github.com/Alviun/ops-releases/releases/latest/download/OPS-Installera.exe)**

Öppna filen och klicka på **Installera**. Den lilla installern hämtar spelet och startaren åt dig. Under tiden kan du spela ett enkelt point-and-shoot.

Windows 10/11, 64 bitar. Internet behövs för nedladdningen. Första installationen hämtar cirka 533 MB.

## Uppdatera

Öppna **OPS-startaren** och sök efter uppdateringar. Startaren hämtar ett mindre uppdateringspaket när det finns ett som passar din installerade version. Alla i en multiplayer-match behöver samma spel- och kartversion.

[Alla utgåvor och ändringar](https://github.com/Alviun/ops-releases/releases)

Det här är spelets nedladdningssida. Licensinformation för ingående komponenter följer med installationen.
